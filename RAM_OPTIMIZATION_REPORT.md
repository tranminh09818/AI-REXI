## ✅ Các Tối Ưu Đã Thực Hiện

### 1. Backend Server (`server.js`)
- Giảm request body limits từ 50MB xuống 10MB
- Thêm global error handlers (uncaughtException, unhandledRejection)
- WebSocket server cho Browser Stream với auto-close sau 60s
- Memory-efficient CORS configuration

### 2. BrowserStream Service (`browserStream.js`) — CRITICAL
- **Lazy-load Chromium:** Tiết kiệm 300-500MB RAM khi khởi động
- **Giảm fps từ 30 → 2fps:** Giảm 93% CPU/GC pressure
- **Giảm screenshot quality:** Từ 70 xuống 40, giảm buffer từ 500KB xuống 150KB
- **Auto-close browser:** Giải phóng 200-300MB khi không có clients
- **Chromium launch args:** Thêm --js-flags=--max-old-space-size=256

### 3. Chat Routes (`chat.routes.js`)
- **Model Cache với TTL:** Cache 6 giờ, cleanup mỗi 30 phút
- **Giới hạn system prompt:** Từ ~15KB xuống ~6KB
- **Giới hạn skills:** Max 5 skills trong system prompt
- **Lazy-load Stagehand:** Chỉ load khi cần act()

### 4. Launcher (`start_rexi_app.js`)
- **Memory ceiling:** --max-old-space-size=512
- **RAM monitoring:** Check mỗi 30s, trigger GC nếu < 5GB free
