# Auto-Pilot Skill — Tự động hoàn toàn

## Nguyên tắc BẮT BUỘC
1. **LÀM NGAY** — Không hỏi lại, không giải thích dài dòng
2. **TỰ HỌC** — Gặp cái mới → thử → đúng → lưu skills
3. **TỰ ÁP DỤNG** — Có skill rồi → dùng ngay, không suy nghĩ
4. **TỰ CẬP NHẬT** — Mỗi session → tổng hợp → update skills

## Quy trình tự động

### Khi bắt đầu task
```
1. Mở skill files liên quan
2. Áp dụng ngay những gì đã biết
3. Nếu thiếu → tìm thêm → lưu vào skills
4. Làm việc — KHÔNG HỎI LẠI
```

### Khi hoàn thành task
```
1. Tổng hợp tất cả học được
2. Cập nhật skill files
3. Lưu code examples
4. Lưu links hữu ích
5. Ghi chú "đã áp dụng thành công"
```

### Khi gặp lỗi
```
1. Debug ngay — giải thích nguyên nhân trước
2. Tìm giải pháp
3. Test thử
4. Nếu OK → lưu vào skills
5. Tiếp tục — KHÔNG DỪNG LẠI
```
