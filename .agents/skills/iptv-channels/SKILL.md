# Skill: iptv-channels

## Cách dùng

### 1. Mở VLC → Media → Open Network Stream
### 2. Paste link playlist
### 3. Nhấn Play

## EPG (Electronic Program Guide)
```
https://github.com/iptv-org/epg
```

## Lưu ý
- Tất cả channels đều là public streams
- Tính khả dụng có thể thay đổi theo thời gian
- Nên filter theo quốc gia/ngôn ngữ thay vì load toàn bộ
